# Personal Finance Analyzer 💰

A Python-based Personal Finance Analyzer that helps users manage and analyze their transaction records.

## Features

* Add transactions
* Automatic category detection
* View all transactions
* Category-wise summary
* Monthly summary
* Detect recurring charges
* Calculate total and average transaction amounts
* Save records to a file
* Load records from a file

## Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* Loops
* Conditional Statements
* String Manipulation
* File Handling
* Exception Handling

## Categories

The application automatically detects categories based on keywords.

Examples:

* Zomato → Food
* Swiggy → Food
* Uber → Transport
* Netflix → Subscription
* Electricity → Utilities
* Salary → Income

## How It Works

The user enters:

1. Date
2. Description
3. Amount

The program automatically detects the transaction category and stores the transaction.

Users can then view transaction records, generate summaries, detect recurring charges, and calculate basic financial insights.
